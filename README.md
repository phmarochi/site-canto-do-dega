# Chácara Canto do Dêga

Site da Chácara Canto do Dêga, local de eventos em Ponta Grossa – PR.

Site estático (HTML + CSS + JS puro), pronto para a Vercel sem configuração.

- `index.html`: o site
- `img/`: fotos otimizadas em WebP
- `src/`: fonte do HTML (`head.html` + `page.html`). Edite aqui e rode `./build.sh` para gerar o `index.html`.
